# APP 开发之账号注册方式

## 1. 账号密码

注册时按照要求填入满足条件的账号密码进行注册登录：

- 缺点：账号容易忘记、找回密码也繁琐、无安全保证、无法获得有价值的注册信息、后续还要引导绑定手机号或邮箱。
- 优点：貌似注册时方便一些。

## 2. 邮箱注册

- 缺点：APP 上操作麻烦，还需要单独登录邮箱获取验证码。
- 优点：相对好记、有安全保障、支持海外用户。

## 3. 手机号注册

就是录入手机号码后，发起短信验证的请求，当手机收到相应的短信验证码后，在 APP 中输入验证码，完成注册。

- 缺点：需要加强隐私保护。
- 优点：操作简单、好记、后期可以关联通讯录、安全保障。

## 4. 第三方验证

利用第三方账户（微信、支付宝、微博等等）授权注册登录，无法获得有价值的注册信息。

- 缺点：无法获得有价值的注册信息、后续还要引导绑定手机号或邮箱。
- 优点：操作方便、后期可以通过第三方进行关联推荐、有安全保证。
