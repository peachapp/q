## nextTick 概念

- vue 中视图更新是异步的，使用 nextTick 方法可以保证用户定义的逻辑在更新之后执行。
- 可用于获取更新后的 DOM，多次调用 nextTick 会被合并。

```vue
<template>
  <div id="counter">{{ count }}</div>
</template>

<script>
export default {
  name: "App",
  components: {},
  data() {
    return { count: 0 };
  },
  mounted() {
    this.$nextTick(() => {
      console.log(document.getElementById("counter").innerHTML); // 0
    });
    this.count = 100;
    this.$nextTick(() => {
      console.log(document.getElementById("counter").innerHTML); // 100
    });
  },
};
</script>
```
