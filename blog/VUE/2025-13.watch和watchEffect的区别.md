# 2025-13.watch 和 watchEffect 的区别

- `watchEffect`立即运行一个函数，然后被动地追踪它的依赖，当这些依赖改变时重新执行该函数。
- `watch`侦测一个或多个响应式数据源并在数据源变化时调用一个回调函数。

```js
const effect = new ReactiveEffect(getter, scheduler);
effect.run();

// getter函数
watchEffect(() => {
  app.innerHTML = state.name; // 数据变化后，会调用scheduler，内部会再次触发effect.run()重新运行getter
});

// 1.getter函数 2.cb函数
watch(
  () => state.name, // 数据变化后，会调用scheduler，内部会调用cb函数
  (newVal, oldVal) => {}
);
```
