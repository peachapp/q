# 2025-25.vue 中的过滤器

过滤器实质上不改变原始数据，只是对数据进行加工处理后返回过滤后的数据再进行调用处理，我们也可以理解成纯函数。

```html
{{ message | filterA("arg1", "arg2") | filterB("arg1", "arg2") }}
```

```js
Vue.filter("filterA", function (value) {
  // 返回处理后的值
});
Vue.filter("filterB", function (value) {
  // 返回处理后的值
});
```

> 常见场景：单位转换、千分符、文本格式化、时间格式化等操作。这写个方法不香么？vue3 果断放弃了过滤器...

```html
<p>{{format(number)}}</p>
```

```js
const format = (n) => {
  return parseFloat(n).toFixed(2);
};
```
