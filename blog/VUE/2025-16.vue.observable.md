# 2025-16.Vue.observable

在非父子组件通信时，可以使用`eventBus`或者使用状态管理工具，但是功能不复杂的时候我们可以考虑使用`Vue.observable`。

[Observable 实现](https://github1s.com/vuejs/vue/blob/main/src/core/global-api/index.ts#L47-L51)

```ts
// 2.6 explicit observable API
Vue.observable = <T>(obj: T): T => {
  observe(obj);
  return obj;
};
```
