# 2025-30.vue 中.sync 修饰符

在有些情况下，我们可能需要对一个 prop 进行“双向绑定”，这时可以使用`.sync`来实现。v-model 默认只能双向绑定一个属性，这里就可以通过`.sync`修饰符绑定多个属性。

```html
<my-component :value.sync="xxxx"></my-component>
<!-- 
  编译的后结果：
  with(this) {
    return _c('my-component', {
      attrs: {
        "value": xxxx
      },
      on: {
        "update:value": function ($event) {
          xxxx = $event
        }
      }
    })
  }
-->
```

> vue3 中.sync 语法被移除。
