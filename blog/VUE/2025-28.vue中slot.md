# 2025-28.vue 中 slot

## 什么是插槽

插槽设计来源于 web components 规范草案，利用 slot 进行占位，在使用组件时，组件标签内部内容会分发到对应的 slot 中。

## 什么时候使用它

通过插槽可以让用户更好的对组件进行扩展和定制化。可以通过具名插槽指定渲染的位置。常用的组件例如：弹框组件、布局组件、表格组件、树组件...

## 插槽的分类和原理

- 默认插槽
- 具名插槽

  ```html
  <div>
    <slot name="title"></slot>
    <slot name="content"></slot>
  </div>
  <!-- 
    编译后的结果：
    with(this) {
      return _c('div', [_t("title"), _t("content")], 2)
    }
  -->
  ```

  ```html
  <my-component>
    <h1 slot="title">标题</h1>
    <div slot="content">内容</div>
  </my-component>
  <!-- 
    编译后的结果：
    with(this) {
      return _c('my-component', [_c('h1', {
        attrs: {
          "slot": "title"
        },
        slot: "title"
      }, [_v("标题")]), _c('div', {
        attrs: {
          "slot": "content"
        },
        slot: "content"
      }, [_v("内容")])])
    }
  -->
  ```

- 作用域插槽
  ```html
  <div><slot :article="{title: '标题', content: '内容'}"></slot></div>
  <!-- 
    编译后的结果：
    with(this) {
      return _c('div', [_t("default", null, {
        "article": {
          title: '标题',
          content: '内容'
        }
      })], 2)
    }
  -->
  ```
  ```html
  <my-component>
    <template v-slot="{article}">
      <div>{{article.title}}</div>
      <div>{{article.content}}</div>
    </template>
  </my-component>
  <!-- 
    编译后的结果：
    with(this) {
      return _c('my-component', {
        scopedSlots: _u([{
          key: "default",
          fn: function ({
            article
          }) {
            return [_c('div', [_v(_s(article.title))]), _c('div', [
              _v(_s(article.content))
            ])]
          }
        }])
      })
    }
  -->
  ```

> 普通插槽，渲染在父级，作用域插槽在组件内部渲染！
