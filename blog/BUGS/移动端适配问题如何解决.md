# 移动端适配问题如何解决

## 背景：

项目想支持 PC、移动端

## 解决方案：

- 根据不同端来开发不同页面（成本最高）
- 根据不同端来加载不同 css 样式（可取）
- 根据响应式来运行不同的样式规则（**常用**）
- style 预处理器来做

考虑的问题：

1. 设置视窗，通过元信息配置`meta`：
   ```html
   <meta name="viewport" content="width=device-width,initial-scale=1.0" />
   ```
2. 掌握媒体查询：
   ```css
   body {
     font-size: 16px;
   }
   /**但是在某一些设备尺寸下，这个size是要更改的 */
   /**当我的尺寸 大于xxx 小于xxx 的时候，需要什么样式 */
   @media (min-width: 780px) and (max-width: 1024px) {
     body {
       font-size: 18px;
     }
   }
   ```
3. 弹性布局：flex 布局是一定要学的
   - 主轴方向：flex-direction
   - 对齐方式：justify-content、align-items
   - 弹性属性：flex
4. 图片响应式：
   ```html
   <picture>
     <source srcset="image-large.jpg" media="(min-width: 800px)" />
     <source srcset="image-medium.jpg" media="(min-width: 400px)" />
     <img src="image-small.jpg" alt="Responsive Image" />
   </picture>
   ```
5. rem：rem 单位的基础值有 html 的 font-size 决定：

   ```css
   html {
     font-size: 16px;
   }
   /**响应式改变基础font-size规则 */
   @media (min-width: 780px) and (max-width: 1024px) {
     html {
       font-size: 18px;
     }
   }
   .header {
     font-size: 1rem; /**  */
   }
   ```

6. em：
   ```css
   html {
     font-size: 16px;
   }
   /**响应式改变基础font-size规则 */
   @media (min-width: 780px) and (max-width: 1024px) {
     html {
       font-size: 18px;
     }
   }
   .header {
     font-size: 1rem; /**  */
   }
   .header-title {
     font-size: 0.8em; /**  */
   }
   ```

### 总结：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width,initial-scale=1.0" />
    <title>Responsive Design Example</title>
    <link rel="stylesheet" href="style.css" />
  </head>
  <body>
    <header class="header">
      <h1>Responsive Page</h1>
    </header>
    <main class="container">
      <div class="card">Card 1</div>
      <div class="card">Card 2</div>
      <div class="card">Card 3</div>
      <div class="card">Card 4</div>
    </main>
  </body>
</html>
```

```css
body {
  margin: 0;
  font-family: Arial, sans-serif;
  font-size: 16px;
}
.header {
  height: 10vh;
  width: 100vw;
  background-color: #333;
  color: #fff;
  display: flex;
  align-items: center;
  justify-content: center;
}
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
  padding: 20px;
}
.card {
  flex: 1 1 100%; /**默认每行一个元素 */
  background-color: #f0f0f0;
  padding: 20px;
  box-shadow: 0 2px 5px rgba(0, 0, 0, 0.1);
}

/**媒体查询 */
@media (min-width: 600px) {
  .card {
    flex: 1 1 45%; /**在较大屏幕上每行两个元素 */
  }
}
@media (min-width: 900px) {
  .card {
    flex: 1 1 30%; /**在更大屏幕上每行三个元素 */
  }
}
```
