# 说说对函数式编程思想的理解

## 基本概念：

1.  函数为一等公名，函数封装的方式解决问题
2.  核心概念

    1. 纯函数，没有任何副作用，相同输入（参数）得到相同输出（返回值）

    ```js
    // 纯函数示例
    function add(a, b) {
      return a + b;
    }
    ```

    2. 不可变性
    3. 高阶函数，函数柯里化

    ```js
    // 高阶函数示例
    function withLogging(fn) {
      return function (...args) {
        console.log("Arguments:", args);
        const result = fn(...args);
        console.log("Result:", result);
        return result;
      };
    }
    const addWithLogging = withLogging(add);
    addWithLogging(1, 2); // Arguments: [1,2] Result: 3
    ```

    4. 函数组合，类似于面向对象编程的继承

    ```js
    // 函数组合示例
    const compose =
      (...fns) =>
      (x) =>
        fns.reduceRight((v, fn) => fn(v), x);

    const double = (x) => x * 2;
    const square = (x) => x * x;

    const doubleAndSquare = compose(square, double);
    console.log(doubleAndSquare(3)); // 36
    ```

## 总结优点：

1. 可测试性，更好写单元测试
2. 可维护性
3. 并发
4. 简洁
