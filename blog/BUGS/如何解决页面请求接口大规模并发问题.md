# 如何解决页面请求接口大规模并发问题

**滑动窗口**，算法，专门来控制流量的。

## 背景：

数据采集平台，低代码编辑平台，有序、相对稳定的发送到后端。

## 解决方案：

1. 请求队列。

```js
const queue = [];
queue.push(); // 入队
queue.shift(); // 出队

class RequestQueue {
  constructor(maxConcurrent) {
    this.maxConcurrent = maxConcurrent; // 最大并发请求数
    this.currentConcurrent = 0; // 当前并发请求数
    this.queue = []; // 请求队列
  }

  add(request) {
    return new Promise((resolve, reject) => {
      this.queue.push({ request, resolve, reject });
      this.processQueue();
    });
  }

  processQueue() {
    if (this.queue.length > 0 && this.currentConcurrent < this.maxConcurrent) {
      const { request, resolve, reject } = this.queue.shift();
      this.currentConcurrent++;
      request()
        .then(resolve)
        .catch(reject)
        .finally(() => {
          this.currentConcurrent--;
          this.processQueue();
        });
    }
  }
}

// 使用请求队列
const requestQueue = new RequestQueue(5); // 设定最大并发请求数为5
```

2. 防抖或者节流。

   - 防抖（debounce）：确保在指定时间内函数只执行一次，常用于输入框的搜索建议。
   - 节流（throttle）：确保在指定时间间隔内函数执行一次，常用药窗口的 resize、scroll 事件。
