## 举例：1000w 行表格如何渲染

维格表、飞书表格、钉钉表格，在线表格追求大数据量。

1. 数据足够大，大数据公司，需要在前端显示大量数据，以防卡顿，所以我们需要通过更好的方案实现。
2. 调研这部分方案
   1. dom
   2. 虚拟表格
   3. canvas table
   4. 可视区绘制算法优化
   5. canvas 结合 Webassembly 技术实现（skia + Webassembly）。
3. 我封装了画布表格引擎，解决了上述问题，并且能够实现 1000w 行数据价值流畅交互。
4. 在这个过程中遇到过哪些问题，我是怎么解决问题的，卡点、难点。
