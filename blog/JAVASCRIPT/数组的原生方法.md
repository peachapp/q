# 数组的原生方法

1.  `concat`：连接两个或多个数组，并返回已连接数组的副本`arr.concat(arr2)`【不改变原数组】。
2.  `slice`：选择数组的一部分，并返回新数组`arr.slice("开始截取的数组下标", "结束截取的数组下标，并且不包含")`【不改变原数组】。
3.  `toString`：将数组转换为字符串，并返回结果【不改变原数组】。
4.  `join`：将数组的所有元素连接成一个字符串，`arr.join("字符")`【不改变原数组】。
5.  `pop`：删除数组的最后一个元素，并返回该元素`arr.pop()`【改变原数组】。
6.  `push`：将新元素添加到数组的末尾，并返回新的数组长度`arr.push("新元素")`【改变原数组】。
7.  `shift`：删除数组的第一个元素，并返回该元素`arr.shift()`【改变原数组】。
8.  `unshift`：将新元素添加到数组的开头，并返回新的数组长度`arr.unshift("新元素")`【改变原数组】。
9.  `reverse`：反转数组中元素的顺序`arr.reverse()`【改变原数组】。
10. `sort`：对数组的元素进行排序`arr.sort((a,b) => { return a-b }); a-b表示升序，b-a>降序；也可以return 数字 <0表示升序，>0表示降序`【改变原数组】。
11. `splice`：从数组中添加/删除/替换元素`arr.splice("开始截取的数组下标", "截取的长度", "被填充替换的数组")`【改变原数组】。
12. `map`：为每个数组元素调用函数，并使用函数的结果创建新数组，返回一个新数组`arr.map((item, index, arr) => { return item + 1}) arr的每个元素+1，并创建一个新数组`。
13. `forEach`：为每个数组元素调用函数`arr.forEach((item, index, arr) => {})`。
14. `filter`：为每个数组元素调用函数，并使用符合条件的元素创建新数组，返回一个新数组`arr.filter((item, index, arr) => { return item > 10}) 过滤arr中大于10的元素，并创建一个新数组`。
15. `find`：为每个数组元素调用函数，查找符合条件的元素返回，只会返回符合条件的第一个，并且停止遍历`arr.find((item, index, arr) => {})`。
16. `findIndex`：为每个数组元素调用函数，查找符合条件的元素返回其索引，只会返回符合条件的第一个，并且停止遍历`arr.findIndex((item, index, arr) => {})`。
17. `some`：检查数组中的任何元素是否通过测试（有真则真）`arr.some((item, index, arr) => {})`。
18. `every`：检查数组中的每个元素是否通过测试（有假则假）`arr.every((item, index, arr) => {})`。
19. `reduce`：为每个数组元素调用`reduce`函数(依次执行)，将其结果汇总为单个返回值。
    `reduce`方法可以搞定的东西特别多，就是循环遍历能做的，reduce 都可以做，比如数组求和、数组求积、统计数组中元素出现的次数、数组去重等等。

    ```js
    // 语法：需要注意的是 initialValue 的值是任意的哈，可以是数组可以是对象
    arr.reduce(callback, initialValue);
    const callback = (prev, currentValue, index, arr) => {};

    // callback （执行数组中每个值的回调函数，包含四个参数）
    /**
     1、prev （上一次回调返回的值，prev 第一次的的值是提供的初始值。 或者是数组的第一项的值。）
      2、currentValue （数组中当前被处理的元素）
      3、index （当前元素在数组中的索引）
      4、array （调用 reduce 的数组）
      */
    ```

    - reduce 累加累乘

    ```js
    // 累加
    let sum = [1, 2, 3, 4, 5].reduce((prev, cur) => prev + cur);
    console.log(sum) //输出 15
    // 累乘
    let sum = [1, 2, 3, 4, 5].reduce((prev,cur) => prev _ cur);
    console.log(sum) //输出 120
    // 累乘，初始值为 10
    let sum = [1, 2, 3, 4, 5].reduce((prev, cur) => prev _ cur, 10);
    console.log(sum) //输出 1200
    ```

    - reduce 数组对象求和

    ```js
    let arr = [
      {
        money: 100,
        name: "苹果",
      },
      {
        money: 50,
        name: "香蕉",
      },
    ];

    //!!!不使用初始值
    function sum(arr) {
      return arr.reduce((prev, cur) => {
        return prev.money + cur.money;
      });
    }

    //!!!使用初始值
    function sum(arr) {
      return arr.reduce((prev, cur) => {
        return cur.money + prev;
      }, 0);
    }
    console.log(sum(arr)); //输出150
    ```

    - reduce 计算数组中每个元素出现的次数[面试经常问]

    ```js
    let names = ["yes", "hello", "hi", "yes", "yy"];
    // 第二个初始值是一个对象，因为有初始值，所以cur的值是数组的第一项[yes]
    let nameNum = names.reduce((pre, cur) => {
      // 第一次pre是一个对象，将这个对象返回，下一次pre又是一个对象了
      if (cur in pre) {
        pre[cur]++;
      } else {
        pre[cur] = 1;
      }
      return pre;
    }, {});
    console.log(nameNum); //{yes: 2, hello: 1, hi: 1, yy: 1}
    ```

20. `split`：以字符为标准分割字符串，返回数组`str.split("字符")`。
