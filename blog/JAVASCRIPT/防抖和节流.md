# 防抖和节流

防抖和节流的作用都是在高频事件中防止函数被多次调用，是一种性能优化的方案。

区别在于：防抖函数只会在高频事件结束后一段时间调用一次函数；节流函数会在高频事件触发过程中每隔一段时间调用一次函数。（防抖是单位时间内只执行最后一次，节流是单位时间内只执行第一次。）

应用场景：

常见的应用场景都是使用高频事件来调用函数的过程当中。\
比如：应用于 window 对象的 resize、scroll 事件，拖拽时的 mousemove 事件，文字输入，自动完成的 keyup 事件。

## 防抖

防抖： 触发高频事件一段时间后（`wait`）只会执行一次函数，如果指定时间内（`wait`）高频事件再次被触发，则重新计算时间。

```js
function debounce(func, wait) {
  let timeout = null;
  return function () {
    let context = this;
    let args = arguments;
    if (timeout) {
      clearTimeout(timeout);
    }

    timeout = setTimeout(function () {
      func.apply(context, args);
    }, wait);
  };
}
```

防抖多用于：

1. 表单验证。（用户输入用户名、手机号时，最后一个字母输入后再验证。）
2. 按钮提交事件。（一个按钮发送请求时，最后一次点击才发送。）
3. 浏览器窗口缩放，`resize`事件，当窗口确定大小时才渲染，防止重复渲染。（如窗口停止改变大小之后重新计算布局。）
4. 输入框内容联想。（搜索框输入查询，如果用户一直在输入中，没有必要不停地去请求服务端接口，等用户停止输入的时候，再调用，设置一个合适的时间间隔，有效减轻服务端压力。）
5. scroll 滚动触发事件。

## 节流

节流：规定在一个单位时间内，只能触发一次函数，如果这个单位时间内触发多次函数，只有一次生效。

```js
function throttle(func, wait) {
  let timeout = null;
  return function () {
    let context = this;
    let args = arguments;
    if (!timeout) {
      timeout = setTimeout(function () {
        timeout = null;
        func.apply(context, args);
      }, wait);
    }
  };
}
```

节流多用于：

1. 滚动加载更多。（监听滚动事件判断是否到页面底部自动加载更多）。
2. 搜索联想。(`keyup`)。
3. DOM 元素的拖拽功能实现。（`mousemove`）。
4. 计算鼠标移动的距离。(`mousemove`)。
5. Canvas 模拟画板功能。(`mousemove`)。
6. 射击游戏的`mousedown/keydown`事件。（单位时间只能发射一颗子弹）。
7. `mousehover`。
